# Final Demo Checklist

Use this exact sequence during the demonstration:

1. Start app.
2. Run `/help`.
3. Ask a normal academic question.
4. Ask a follow-up that requires memory.
5. Run `/clear`.
6. Ask the old-context question again.
7. Ask a RAG question based on the supplied documents.
8. Run `/sources`.
9. Ask a question intentionally absent from the knowledge base.
10. Run `/quiz`.
11. Enter an invalid command.
12. Explain environment-variable API-key storage.
13. Show `.gitignore`.
14. Explain the RAG pipeline.
15. Show the tests and evaluation script.

Never show a real API key.
